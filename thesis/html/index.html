1. Website làm gì?

laptop.khannv.vn là cửa hàng bán laptop trực tuyến, viết bằng ASP.NET MVC 5, dữ liệu SQL Server catalog laptopstore.

  • Khách: xem sản phẩm, tìm kiếm, lọc hãng, giỏ hàng, đặt hàng, đăng ký/đăng nhập.
  • Admin: quản lý sản phẩm, đơn hàng, xuất Excel, báo cáo doanh thu. Tài khoản demo: Admin / admin.

2. Chạy lại chương trình (tóm tắt)

  1. Cài Visual Studio (workload ASP.NET), .NET 4.8, SQL Server.
  2. Chạy script setup/database.sql để tạo database laptopstore.
  3. Mở src/ProTechTiveGear.sln → F5.
  4. Shop: http://localhost:51494/Shop/Index — Admin: /Admin.

Chi tiết: file README.md ở gốc repository và setup/HUONG_DAN_CAI_DAT.md (nếu có).

3. Hướng dẫn thuyết trình / demo tính năng

Mở sẵn hai tab: trang khách và trang Admin đã đăng nhập.

Khách hàng

  1. Trang chủ: banner, hãng nổi bật, lưới laptop.
  2. Ô tìm kiếm: gõ ASUS hoặc HP. Giải thích LINQ Contains ≈ SQL LIKE '%…%'.
  3. Menu hãng → danh sách máy của hãng đó.
  4. Chi tiết sản phẩm → thêm giỏ → đặt hàng.
  5. Đăng nhập khách: /Login/Login.
Nói một câu: “Khách mua hàng trên web; đơn lưu bảng Order; admin xử lý sau.”

Quản trị

  1. Đơn hàng: /Admin/AllListOrder — lọc tab, tìm mã/khách.
  2. Nút Xuất dữ liệu → file Excel.
  3. Báo cáo doanh thu: menu Đơn hàng hoặc /Admin — lọc ngày, số liệu đã thu / chưa TT, theo sản phẩm.
Nói: “Đây là chức năng thống kê số liệu phục vụ quản lý cửa hàng.”
