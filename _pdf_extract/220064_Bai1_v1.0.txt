6Giới thiệu .NET Framwork
.NET Framework là sản phẩm của Microsoft, giúp 
cho việc phát triển các ứng dụng dễ dàng hơn
.NET Framework là khung sườn cho việc xây dựng 
và phát triển các ứng dụng web
.NET Framework bao gồm: NET Framework Class 
Library và Common Language Runtime (CLR).
NET Framework Class Library chứa hàng nghìn lớp 
bên trong, cung cấp các dịch vụ để xây dựng các 
ứng dụng
Common Language Runtime có nhiệm vụ thực thi 
mã ứng dụng
